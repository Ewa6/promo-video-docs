# Promo video skill documentation

User documentation for the promo video skill, a Claude Code skill that turns a software product into short, narrated marketing videos.

- Read the docs: https://ewa6.github.io/promo-video-docs/
- The Markdown pages are in [`docs/`](docs). The site generator is in [`site/`](site).
